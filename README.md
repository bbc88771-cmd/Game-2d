# Sunset of the World — веб-прототип

2D top-down приключение/выживание/RPG по ТЗ (рабочее название «Sunset of the
World»). Это **веб-версия** игры (HTML/CSS/JS): её можно запускать, тестировать и
публиковать бесплатно в браузере. Позже геймплей переносится на Unity для
Steam-релиза (решение «веб сейчас, Unity потом»).

> Почему веб, а не сразу Unity: в облачном окружении Unity нельзя собрать и
> запустить бесплатно (Unity отключил бесплатную CI-активацию Personal-лицензий).
> Веб-прототип играбелен сразу и проверяется на каждом шаге.

## Что готово

**Главное меню** (`index.html`) в стиле присланного референса: тёмная панель
слева, светящийся «затменный» логотип, лес на закате с лавовыми трещинами.

Кнопки:
- **Новая игра** → выбор сложности (5 уровней из ТЗ) → выбор героя (5 классов) →
  интро **«Некого»** (чёрный экран, красные светящиеся буквы — как описано в
  присланном документе по мультиплееру/нарративу).
- **Продолжить** — активна, если есть сохранение.
- **Создать лобби** — генерирует код для друзей, показывает список игроков
  (до 5). *Сетевой слой пока имитируется локально — каркас под реальную синхру.*
- **Ввести код** — вход в лобби друга по коду.
- **Настройки** — музыка/звук, язык (ru/en), сложность по умолчанию, фуллскрин.
- **Дневник** — окно дневника (наполняется по ходу игры).
- **Выход** — подтверждение выхода.
- **Моды** (внизу) — включение/отключение модов.

## Запуск локально

```bash
cd Game-2d
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Игра онлайн (бесплатно, GitHub Pages)

Workflow **Deploy web to GitHub Pages** публикует игру при пуше.
Один раз включите: **Settings → Pages → Source = GitHub Actions**.
Адрес: `https://<owner>.github.io/<repo>/`.

## Структура

```
Game-2d/
├── index.html              # разметка меню + модалки + интро «Некого»
├── css/menu.css            # стиль дарк-фэнтези, левая панель, кнопки, модалки
├── js/menu.js              # логика всех кнопок, лобби, настроек, интро
├── assets/img/
│   └── background.jpg       # оригинальный арт меню (фон + логотип)
└── .github/workflows/pages.yml
```

## Арт

`assets/img/background.jpg` — **оригинальный арт меню** (кадр игрового окна из
присланного скриншота): сохранены лес-на-закате и логотип «Sunset of the World».
Старые кнопки убраны с картинки, а весь список кнопок рисуется поверх тёмной
панели вживую (`css/menu.css` + `js/menu.js`) — так стиль остаётся оригинальным,
а кнопки можно добавлять/менять. Чтобы поставить более качественный исходник —
замените `background.jpg` (логотип можно вынести отдельным слоем при желании).

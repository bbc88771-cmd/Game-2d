# Внешние ассеты (asset kit)

## Tiny Swords — Pixel Frog

- **Папка:** `assets/kit/tiny-swords/`
- **Автор:** Pixel Frog
- **Источник:** https://pixelfrog-assets.itch.io/tiny-swords
- **Лицензия:** бесплатно для коммерческого и некоммерческого использования
  (CC0-подобная, атрибуция не требуется, но указана из уважения к автору).
- **Состав:** террейн (трава/песок/вода/мост/тайлы), фракции Knights
  (Pawn/Archer/Warrior + анимации, Dead) и Goblins (Torch/TNT/Barrel),
  здания (Castle/Tower/House/Wood_House/Wood_Tower), ресурсы (деревья,
  золотая шахта, овцы, иконки ресурсов), деко, эффекты, UI (кнопки/иконки).

Используется как основной набор пиксель-арта для геймплея (тайлы карты,
персонажи и их анимации, ресурсы, постройки). Файлы взяты без изменений.

Скачано в сессии через `raw.githubusercontent.com` / `codeload.github.com`
(прямой доступ к произвольным репозиториям через GitHub API в этом окружении
ограничен).

# Sunset of the World — порт на Unity

Перенос игры «Некий» (веб-версия в корне репозитория) на **Unity 2022.3 LTS** / C#.
Лежит здесь, в папке `unity/`, чтобы не мешать веб-версии.

## Что уже перенесено (фаза 1 — ядро, проверено)

Модуль `Assets/Sunset/` (отдельная сборка `Sunset`, ни от чего не зависит, кроме
TextMeshPro/UGUI):

| Файл | Что это |
|------|---------|
| `Core/NekoBrain.cs` | «Мозг» диалога: классификация ввода, ~37 тем лексикона мира, внутримировой редирект (вопросы вне мира возвращаются к игре), конкретные ответы о игроке (город/время/система), шкалы доверия/тьмы, настроение, путь к концовке, анти-повтор (без повтора подряд) |
| `Core/NekoState.cs` | Состояние «Некого» и отношений + `PlayerProbe` (скан игрока). Сериализуемо |
| `Core/LobbyGate.cs` | Разблокировка локаций в лобби и условие старта (выбранную локацию должны открыть все) |
| `Core/SunsetSave.cs` | Сохранение в `PlayerPrefs` (JsonUtility) |
| `Data/GameLocations.cs` | 5 локаций-островов |
| `Tests/*` | EditMode-тесты (NUnit): классификация, редирект, лексикон, self-ответы, анти-повтор, настроение/концовка, лобби-гейт |

Логика — чистый C# без зависимостей от сцены. Перед коммитом собрана компилятором
Mono и прогнана отдельным харнессом — все проверки зелёные.

## Как открыть

1. Unity Hub → **Add → Add project from disk** → выбрать папку `unity/`.
2. Открыть (Unity подтянет пакеты, создаст `Library/`).
3. **Window → General → Test Runner → EditMode → Run All** — прогнать тесты «мозга» и лобби.

## Что дальше (фаза 2 — UI/сцены)

Ещё не перенесено и планируется отдельным заходом:
- экран диалога с «Неким» (TextMeshPro-чат, печатающийся текст, ввод);
- полноэкранный «красный код» + скан-«досье» игрока;
- катсцена (4 слайда);
- меню с фоном/логотипом;
- лобби с каруселью локаций (логика гейта уже есть в `LobbyGate`).

UI планируется строить из кода (как в `SceneBuilder` соседнего проекта), чтобы
не хранить хрупкие `.unity`/`.prefab`.
